# 核心功能与操作指南 (Features & Guides)

本文档详细介绍了「枫叶云笔记」的各个主要功能模块、交互逻辑及使用说明。

---

## 🗂️ 1. 文件夹树与多层级管理

### 1.1 无限层级与折叠展开
- 侧边栏支持展开/折叠各级文件夹；
- 移动笔记弹窗提供「展开全部」和「折叠全部」按钮，以及层级模糊搜索。

### 1.2 拖拽重排序与层级变换
左侧导航区文件夹支持拖拽操作，系统根据鼠标在目标项垂直区域的位置智能判定拖拽意图：
- **上方 28% 区域**：显示顶部蓝色指示线与圆点，松开后将当前文件夹移动到目标文件夹**同级的上方**；
- **下方 28% 区域**：显示底部蓝色指示线与圆点，松开后将当前文件夹移动到目标文件夹**同级的下方**；
- **中部 44% 区域**：目标文件夹高亮显示背景与边框，松开后将文件夹作为**子文件夹**移动入内；
- **防循环保护机制**：系统内置防循环检测，禁止将文件夹拖拽至其自身或后代子文件夹中。

## 🧠 2. 思维导图编辑器 (MindMap Editor)

### 2.1 节点编辑与操作
- **新增子节点**：按下 `Tab` 或 `Insert` 键；
- **新增同级节点**：按下 `Enter` 键；
- **编辑文本**：双击节点或按下 `F2` / `Space`；
- **删除节点**：按下 `Delete` 或 `Backspace` 键；
- **收起/展开分支**：点击节点旁边的 `+/-` 按钮或按下 `/`。

### 2.2 大纲视图双向同步
- 支持一键打开左侧/侧边「大纲视图」；
- 大纲视图中的文本修改、层级调整与增删节点会实时同步至可视化思维导图画布。

### 2.3 属性与标签
- **优先级**：支持 1~9 级优先级图标标记；
- **完成进度**：支持 1/8 到全部完成等多档进度状态；
- **超链接与备注**：支持为任意节点添加 Markdown 备注与外链。

### 2.4 主题与结构布局
- 支持自由切换「经典脑图」、「向右逻辑图」、「组织结构图」、「鱼骨图」等布局结构；
- 预置多种精美主题配色（天空蓝、极光紫、经典商务等）。

---

## 📝 3. Markdown 富文本笔记编辑器 (Note Editor)

### 3.1 功能工具栏
- 快速应用标题（H1 ~ H4）、加粗、斜体、删除线、代码块、引用块；
- 一键插入无序列表、有序列表、待办 Checklist、表格、分隔线及超链接。

### 3.2 统计与全屏模式
- 底部状态栏实时统计字符数、字数及阅读预估时间；
- 支持沉浸式全屏专注写作模式。

---

## 📥 4. 导入与导出规范 (Import & Export)

| 格式 | 支持类型 | 说明 |
| :--- | :--- | :--- |
| **XMind** | 导入 (`.xmind`) | 解析 XMind 压缩包中的 `content.json` 或 `content.xml`，自动转换为思维导图笔记 |
| **Markdown** | 导入 / 导出 (`.md`) | 导入为 Markdown 笔记或转换为思维导图大纲；思维导图可导出为 Markdown |
| **PNG 图片** | 导出 (`.png`) | 基于 SVG 画布渲染高清 PNG 图像并提供下载 |
| **SVG 矢量图** | 导出 (`.svg`) | 导出无损矢量图形代码与文件 |
| **JSON** | 导入 / 导出 (`.json`) | 导出/导入包含完整节点结构、样式及元数据的原生 JSON |
